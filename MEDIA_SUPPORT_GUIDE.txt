طريقة دعم الوسائط لأي بوت آخر

1) المتطلبات
- SDK للمنصة (مثل WhatsApp/Telegram/Discord) يدعم تنزيل الوسائط
- واجهة ذكاء اصطناعي تدعم إدخال صور/صوت (مثل Gemini/Claude/GPT Vision)
- تخزين سياق المحادثة (قاعدة بيانات أو ذاكرة مؤقتة)

2) تدفق العمل العام (Pipeline)
- استقبل الرسالة
- اكتشف نوع الرسالة: نص/صورة/صوت/ملف
- إذا كانت وسائط: قم بتنزيلها وحوّلها إلى base64 مع mimeType
- جهّز سياق المستخدم (آخر رسائل + بيانات الحساب)
- أرسل للنموذج: نص + أجزاء الوسائط (inlineData)
- لو النموذج طلب تنفيذ أداة: نفذ الأداة ثم أعد النتيجة للنموذج
- أرسل الرد النهائي للمستخدم

3) مثال إرسال الوسائط إلى نموذج متعدد الوسائط (Pseudo)
request = {
  contents: [
    { role: "user", parts: [
        { text: contextText },
        { text: messageText },
        { inlineData: { data: mediaBase64, mimeType: mediaMimeType } }
    ]}
  ],
  tools: [{ functionDeclarations: toolDefinitions }]
}
response = model.generateContent(request)

5) قواعد تعامل موصى بها
- الاستيكر: تجاهله افتراضياً إلا إذا كان هناك نص مرافق
- وسائط غير مدعومة: رد برسالة قصيرة توضح الأنواع المدعومة
- فشل تنزيل الوسائط: أعد محاولة واحدة ثم أخبر المستخدم
- لا تفترض تنفيذ أي إجراء بدون استدعاء الأداة
