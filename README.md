# WhatsApp Agent للمتجر الإلكتروني

بوت WhatsApp ذكي لمتجر إلكتروني يستخدم Gemini AI للرد على الاستفسارات، اقتراح المنتجات، وإنشاء الطلبات.

## المميزات

- 🤖 **ذكاء اصطناعي متقدم**: استخدام Gemini 3.5 Flash للتفاعل الذكي مع العملاء
- 🛍️ **إدارة المنتجات**: جلب وعرض المنتجات من API المتجر
- 🛒 **إنشاء الطلبات**: جمع معلومات الطلب وإنشاؤه تلقائياً
- 💳 **إدارة الدفع**: إرسال روابط الدفع تلقائياً بعد إنشاء الطلب
- 💬 **حفظ السياق**: حفظ محادثات العملاء في قاعدة بيانات SQLite
- 🌐 **دعم اللغة العربية**: تفاعل كامل باللغة العربية فقط
- ⚡ **Function Calling**: استخدام Function Calling مع Gemini للتفاعل مع APIs

## المتطلبات

- Node.js 18 أو أعلى
- npm أو yarn
- حساب Google Cloud للحصول على Gemini API Key
- حساب WhatsApp للاتصال بالبوت
- API للمتجر (Soapy Bubbles)

## التثبيت

### 1. استنساخ المشروع

```bash
git clone <repository-url>
cd soapy_whatsapp_agent
```

### 2. تثبيت المكتبات

```bash
npm install
```

### 3. إعداد ملف البيئة

أنشئ ملف `.env` في جذر المشروع:

```env
GEMINI_API_KEY=your_gemini_api_key_here
API_BASE_URL=https://api.soapy-bubbles.com/api/v1
DATABASE_PATH=./data/conversations.db
LOG_LEVEL=info
CUSTOMER_IP=0.0.0.0
ADMIN_PHONES=965XXXXXXXXX,965YYYYYYYYY
```

**ملاحظة عن ADMIN_PHONES**:
- أضف أرقام الهواتف للمالكين الإداريين (مفصولة بفواصل)
- الصيغة: `965XXXXXXXXX` (بدون + أو 00)
- المالكون الإداريون فقط يمكنهم استخدام دوال الحظر (block_number, unblock_number, list_blocked_numbers)

**ملاحظة**: يمكنك نسخ `.env.example` كقالب:

```bash
cp .env.example .env
```

ثم قم بتعديل القيم حسب احتياجاتك.

## الإعداد الأولي

### 1. الحصول على Gemini API Key

1. اذهب إلى [Google AI Studio](https://makersuite.google.com/app/apikey)
2. سجل الدخول بحساب Google
3. أنشئ API Key جديد
4. انسخ المفتاح وأضفه في ملف `.env`

### 2. ربط WhatsApp

1. شغل البوت باستخدام `npm run dev`
2. سيظهر QR Code في Terminal
3. افتح WhatsApp على هاتفك
4. اذهب إلى **الإعدادات** > **الأجهزة المرتبطة**
5. اضغط على **"ربط جهاز"** وامسح QR Code
6. انتظر حتى يظهر "WhatsApp client is ready!"

## Functions المتاحة للبوت

البوت يستخدم Function Calling مع Gemini للتفاعل مع APIs:

### 1. search_products
البحث عن المنتجات بناءً على استفسار العميل

**المعاملات**:
- `query` (مطلوب): كلمات البحث
- `category` (اختياري): فئة المنتج

### 2. get_product_details
الحصول على تفاصيل منتج محدد

**المعاملات**:
- `product_id` (مطلوب): معرف المنتج

### 3. get_featured_products
جلب المنتجات المميزة

### 4. calculate_order_total
حساب إجمالي الطلب

**المعاملات**:
- `items` (مطلوب): قائمة المنتجات والكميات
- `shipping_amount` (مطلوب): تكلفة الشحن

### 5. create_order
إنشاء طلب جديد

**المعاملات**:
- `customer_name` (مطلوب): اسم العميل
- `customer_phone` (مطلوب): رقم الهاتف
- `customer_email` (مطلوب): البريد الإلكتروني
- `shipping_address` (مطلوب): عنوان الشحن
- `items` (مطلوب): قائمة المنتجات
- `shipping_amount` (مطلوب): تكلفة الشحن

### 6. get_payment_methods
جلب طرق الدفع المتاحة

### 7. initiate_payment
تهيئة الدفع وإنشاء رابط الدفع

**المعاملات**:
- `order_id` (مطلوب): معرف الطلب
- `payment_method` (مطلوب): طريقة الدفع

## سير عمل إنشاء الطلب

1. **الاستفسار**: المستخدم يطلب منتج أو يريد عمل طلب
2. **جمع المعلومات**: البوت يجمع المعلومات المطلوبة تدريجياً:
   - الاسم (customer_name)
   - البريد الإلكتروني (customer_email)
   - العنوان (shipping_address):
     - الشارع (street)
     - المدينة (city)
     - المحافظة (governorate)
     - الرمز البريدي (postal_code)
   - المنتجات والكميات (items)
3. **حساب الإجمالي**: البوت يحسب الإجمالي باستخدام `calculate_order_total`
4. **إنشاء الطلب**: البوت ينشئ الطلب باستخدام `create_order`
5. **جلب طرق الدفع**: البوت يجلب طرق الدفع المتاحة
6. **تهيئة الدفع**: البوت يهيئ الدفع تلقائياً
7. **إرسال رابط الدفع**: البوت يرسل رابط الدفع للمستخدم تلقائياً

## قاعدة البيانات

البوت يستخدم SQLite لحفظ البيانات:

### جداول قاعدة البيانات

1. **conversations**: حفظ تاريخ المحادثات
   - `id`: المعرف الفريد
   - `phone`: رقم الهاتف
   - `messages`: الرسائل (JSON)
   - `order_data`: بيانات الطلب (JSON)
   - `metadata`: بيانات إضافية (JSON)
   - `created_at`: تاريخ الإنشاء
   - `updated_at`: تاريخ التحديث

2. **orders**: حفظ معلومات الطلبات
   - `id`: المعرف الفريد
   - `order_id`: معرف الطلب من API
   - `phone`: رقم الهاتف
   - `order_data`: بيانات الطلب (JSON)
   - `payment_url`: رابط الدفع
   - `status`: حالة الطلب
   - `created_at`: تاريخ الإنشاء
   - `updated_at`: تاريخ التحديث

البيانات محفوظة في: `./data/conversations.db`

## الأمان والحماية من Spam

### نظام الحظر ومعدل الرسائل

البوت يتضمن نظاماً متقدماً للحماية من Spam والإساءة:

#### 1. نظام معدل الرسائل (Rate Limiting)
- **الحد الأقصى**: 5 رسائل في الدقيقة الواحدة
- **النافذة الزمنية**: 10 رسائل في 5 دقائق
- **الحظر التلقائي**: يتم حظر الأرقام التي ترسل رسائل كثيرة بسرعة (أقل من ثانيتين بين الرسائل)

#### 2. نظام الحظر (Blocking)
- **الحظر اليدوي**: يمكن للبوت حظر أرقام معينة بناءً على طلب
- **الحظر التلقائي**: يتم حظر الأرقام تلقائياً عند اكتشاف نمط Spam
- **قائمة الأرقام المحظورة**: يمكن عرض جميع الأرقام المحظورة

#### 3. معالجة رسالة واحدة في الوقت الفعلي
- **منع اختلاط المحادثات**: كل محادثة تُعالج رسالة واحدة في الوقت الفعلي
- **قائمة الانتظار**: الرسائل الواردة تُوضع في قائمة انتظار حتى اكتمال المعالجة
- **حماية من التداخل**: يضمن عدم معالجة رسائل متعددة في نفس الوقت من نفس الرقم

#### 4. دوال الحظر (للإدارة)
- `block_number`: حظر رقم هاتف مع سبب (دالة إدارية)
- `unblock_number`: إلغاء حظر رقم هاتف (دالة إدارية)
- `list_blocked_numbers`: عرض قائمة الأرقام المحظورة (دالة إدارية)

### جداول قاعدة البيانات الجديدة

#### blocked_numbers
- `id`: المعرف الفريد
- `phone`: رقم الهاتف المحظور
- `reason`: سبب الحظر
- `blocked_by`: من قام بالحظر (system, rate_limiter, bot)
- `created_at`: تاريخ الحظر
- `updated_at`: تاريخ التحديث

#### message_rate_tracking
- `id`: المعرف الفريد
- `phone`: رقم الهاتف
- `message_count`: عدد الرسائل في النافذة الزمنية
- `window_start`: بداية النافذة الزمنية
- `last_message_time`: وقت آخر رسالة
- `created_at`: تاريخ الإنشاء
- `updated_at`: تاريخ التحديث

## الأمان

- **مفاتيح API**: لا تشارك ملف `.env` أبداً وأضفه إلى `.gitignore`
- **قاعدة البيانات**: احفظ نسخة احتياطية من قاعدة البيانات بانتظام
- **WhatsApp**: استخدم رقم هاتف مخصص للبوت
- **البيانات الحساسة**: لا تخزن بيانات حساسة في قاعدة البيانات بدون تشفير
- **الحماية من Spam**: النظام يحمي البوت من الرسائل المزعجة والإساءة تلقائياً

## استكشاف الأخطاء

### البوت لا يرد

1. تحقق من أن البوت متصل بـ WhatsApp:
   - ابحث عن "WhatsApp client is ready!" في السجلات
   - إذا لم يظهر، امسح QR Code مرة أخرى

2. تحقق من سجلات الأخطاء في Terminal

3. تأكد من صحة Gemini API Key:
   - تحقق من المفتاح في ملف `.env`
   - تأكد من أن المفتاح صحيح وغير منتهي الصلاحية

### خطأ في إنشاء الطلب

1. تحقق من اتصال API المتجر:
   - تأكد من أن `API_BASE_URL` صحيح
   - تحقق من أن API يعمل

2. تحقق من صحة البيانات المدخلة:
   - تأكد من أن جميع الحقول المطلوبة موجودة
   - تحقق من صحة تنسيق البريد الإلكتروني والعنوان

3. راجع سجلات الأخطاء:
   - ابحث عن أخطاء في Terminal
   - تحقق من رسائل الخطأ من API

### خطأ في قاعدة البيانات

1. تأكد من وجود مجلد `data/`:
   ```bash
   mkdir -p data
   ```

2. تحقق من صلاحيات الكتابة:
   - تأكد من أن التطبيق لديه صلاحيات الكتابة في المجلد

3. راجع سجلات الأخطاء:
   - ابحث عن أخطاء قاعدة البيانات في Terminal

### خطأ في Gemini API

1. تحقق من المفتاح:
   - تأكد من أن `GEMINI_API_KEY` صحيح
   - تحقق من أن المفتاح نشط

2. تحقق من الحصة (Quota):
   - تأكد من أن لديك حصة كافية في Gemini API
   - راجع استخدام API في Google Cloud Console

3. راجع سجلات الأخطاء:
   - ابحث عن أخطاء Gemini API في Terminal
